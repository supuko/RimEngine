# RimEngine

### Lightweight Video Editing Software Preserving Original Quality.

RimEngine is a video and image editing application built with one goal in mind: making high-quality editing accessible without unnecessarily demanding system resources.

At its core, RimEngine uses demand-driven frame decoding and memory-bounded caching. Rather than decoding entire videos in advance, it processes frames as they are needed and manages cached data within defined memory limits.

Our goal is to make editing smoother, reduce unnecessary resource usage, and preserve original media quality throughout the editing process.

### What RimEngine Offers

- Video editing and timeline-based workflows.
- Image editing with pixel-level precision.
- Multi-layer image editing.
- Demand-driven frame decoding.
- Memory-bounded frame caching.
- Video and image exporting.
- Non-destructive handling of source media.

### What We're Working Towards

- **Adaptive Processing:** Allocate processing resources according to the current editing task.
- **Intelligent Frame Scheduling:** Prioritize relevant frames and avoid wasting resources on outdated requests.
- **Efficient Memory Management:** Keep memory usage controlled, even with demanding projects.
- **Selective Rendering:** Reprocess only the parts of an image or timeline affected by an edit, where possible.
- **Quality-Preserving Exports:** Use original source media and full-quality processing for final output.
- **Unified Editing:** Bring video and image editing together under shared media and rendering infrastructure.

### Our Goal

We want to make editing software that respects both your hardware and your media. No unnecessary resource usage, no needless quality loss, just the tools to work with your content.
